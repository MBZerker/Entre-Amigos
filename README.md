# Entre Amigos — distribuição

Este repositório contém exclusivamente os arquivos públicos do GitHub Pages usados para compartilhamento e atualização do Entre Amigos.

O código-fonte Android, o backend, credenciais, chaves de assinatura e APKs administrativos não devem ser adicionados aqui. APKs públicos somente entram depois da aprovação explícita da versão candidata.
